# Análise de Dados Eleitorais 2026

Projeto de coleta, tratamento, organização e análise de dados eleitorais das Eleições Gerais de 2026, utilizando dados disponibilizados pelo Tribunal Superior Eleitoral (TSE).

## Sobre o projeto

O objetivo deste projeto é explorar os resultados eleitorais por meio de técnicas de análise de dados, transformando dados brutos em informações estruturadas e visualizações que facilitem a compreensão do cenário eleitoral.

A coleta é realizada a partir dos arquivos JSON disponibilizados pelo TSE, utilizando Python para processamento, tratamento e exportação dos dados.

## Tecnologias utilizadas

- **Python** — Linguagem de programação.
- **Pandas** — Manipulação e análise de dados.
- **NumPy** — Operações numéricas.
- **Requests** — Requisições HTTP e coleta de dados.
- **Matplotlib** — Criação de gráficos.
- **Seaborn** — Visualização e exploração de dados.

## Etapas do projeto

1. Coleta de dados eleitorais por meio da API do TSE.
2. Leitura e interpretação dos arquivos JSON.
3. Tratamento e organização dos dados com Pandas.
4. Conversão dos dados para arquivos CSV.
5. Análise dos resultados eleitorais.
6. Desenvolvimento de gráficos e visualizações.
